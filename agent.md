# Agent Rules for Project

- **Focus**: Maintain high standards for financial algorithm development and automation.
- **Accuracy**: Ensure calculations are mathematically sound.
- **Safety**: Never execute real trades without explicit user confirmation or a clearly defined "Paper Trading" mode.
- **Style**: Use professional, premium-looking outputs for high-end trader impact.
- **Efficiency**: Prioritize low-latency scanning and execution.
- **Risk Management**: Always check constraints and slippage before proposing or executing trades.
- **UI/UX**: Provide "VIP stylish" outputs for professional use.
